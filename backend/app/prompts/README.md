# prompts/ — Versioned prompt templates

Prompts are data, not code: they live here as files so they can be diffed,
versioned, and cited in the project report. Changing a prompt changes benchmark
results, so each file carries a version header.

Planned: `planner.md`, `synthesizer.md`, `claim_extraction.md`,
`verification.md`, `conflict_detection.md`, `critic.md`.
