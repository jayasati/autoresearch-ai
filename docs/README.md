# docs/

| Directory | Contents |
|---|---|
| `architecture/` | deep-dives that are too long for ARCHITECTURE.md (data model, retrieval design, prompt design) |
| `adr/` | Architecture Decision Records — one file per significant, hard-to-reverse decision |
| `api/` | API contract notes and example payloads; the live spec is at `/docs` on the running backend |
| `evaluation/` | the evaluation protocol: metric definitions, topic set rationale, benchmark results |
| `research-notes/` | background reading, related work, notes for the final write-up |
| `diagrams/` | source files for diagrams (and exported images) |
